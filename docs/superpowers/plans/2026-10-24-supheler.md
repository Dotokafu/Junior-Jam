# Şüpheler Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Devletin (Defne) ve örgütün (Vey) senden gizli şüphesi.
- Dosya verme, vermeme, yanlış teşhis, yanlış servis ve aynı türde yanlış içecekle değişir.
- Tedarikçinin tavrı, sorgu sahnesi ve kapı notlarıyla hissedilir.
- Dolunca o tarafın kötü sonu gelir.

**Architecture:**
- **Kurallar:** Saf `SuspicionRules` (`domain/consequences/`) her olayın etkisini hesaplar ve yeni sözlük döndürür.
- **Oturum:** `GameSession` kuralları dört yerde çağırır: teslim, teslimat sonu, servis ve teslimat başı. Ayrıca iki aşama ekler: `questioning` (sorgu) ve `verdict` (tedarikçinin karşılığı).
- **İçerik:** Sayılar `endings.json` → `rules.suspicion` içinde. Metinler `encounter_pools.json` (`suspicion_lines`, `interrogations`, `door_notes`) ve `tr.json` içinde.
- **Gizlilik:** Snapshot şüphe değerlerini taşımaz, yalnızca metinleri taşır.

**Tech Stack:** Godot 4.7.2, GDScript. Testler başsız SceneTree script'leri; görsel test pencereli.

**Kaynak belge:** `docs/superpowers/specs/2026-10-24-supheler-design.md`

**Taraf adları (kodda):**
- `"state"`: devlet, Defne, sabah teslimatı (`morning_supplier`). `_report`'taki `recipient == "human"`.
- `"order"`: örgüt, Vey, gece teslimatı (`night_supplier`). `recipient == "fallen"`.

**Commit notu:** Sorgu çekirdeğindeki gibi görev başına commit, `supheler` dalında. Push yalnızca kullanıcı isterse.

- [ ] **Step 3: Write minimal implementation**

`domain/consequences/suspicion_rules.gd`:

```gdscript
class_name SuspicionRules
extends RefCounted
## Devletin ("state": Defne, sabah) ve örgütün ("order": Vey, gece) senden gizli şüphesi, 0–100.
## Saf kural: her fonksiyon yeni bir sözlük döndürür, verileni değiştirmez. Sayılar içerikten gelir
## (endings.json → rules.suspicion); eksik anahtar varsayılanı kullanır.
const DEFAULTS := {"wary": 34, "threat": 67, "limit": 100, "give_other": 15, "give_streak": 10,
	"give_trust": -10, "wrong_report": 20, "decline": 8, "wrong_serve": 12, "wrong_recipe": 5}
const ENDINGS := {"state": "state_arrest", "order": "order_vanish"}

static func fresh() -> Dictionary:
	return {"state": 0, "order": 0}

static func other(side: String) -> String:
	return "order" if side == "state" else "state"

## Bir tarafa dosya verildi. streak: aynı tarafa bundan önceki ardışık teslim sayısı ("bariz"lık).
## correct: verilen kişi o tarafın istediği türdense; değilse o taraf yanıltılmıştır.
static func after_report(values: Dictionary, side: String, streak: int, correct: bool, rules: Dictionary) -> Dictionary:
	var result := values.duplicate()
	var rival := other(side)
	result[rival] = _clamp(int(result[rival]) + _rule(rules, "give_other") + streak * _rule(rules, "give_streak"), rules)
	result[side] = _clamp(int(result[side]) + (_rule(rules, "give_trust") if correct else _rule(rules, "wrong_report")), rules)
	return result

## Teslimatta tedarikçi sordu, dosya verilmedi.
static func after_decline(values: Dictionary, side: String, rules: Dictionary) -> Dictionary:
	return _add(values, side, _rule(rules, "decline"), rules)

## served_side: içeceğin rafı; customer: müşterinin gerçek türü; order_ok: istediği içecek mi.
## Yanlış raf müşterinin tarafını işkillendirir: insana Fallen içeceği → devlet (polise gider),
## Fallen'a insan içeceği → örgüt (aç kalır). Doğru raf ama başka içecek de biraz işkillendirir.
static func after_serve(values: Dictionary, served_side: String, customer: String, order_ok: bool, rules: Dictionary) -> Dictionary:
	var side := "state" if customer == "human" else "order"
	if served_side != customer:
		return _add(values, side, _rule(rules, "wrong_serve"), rules)
	if not order_ok:
		return _add(values, side, _rule(rules, "wrong_recipe"), rules)
	return values.duplicate()

## Sorgu sahnesindeki cevabın etkisi (içerikte, negatif olabilir).
static func after_answer(values: Dictionary, side: String, effect: int, rules: Dictionary) -> Dictionary:
	return _add(values, side, effect, rules)

static func level(value: int, rules: Dictionary) -> String:
	if value >= _rule(rules, "threat"):
		return "threat"
	if value >= _rule(rules, "wary"):
		return "wary"
	return "calm"

static func reached(values: Dictionary, side: String, rules: Dictionary) -> bool:
	return int(values.get(side, 0)) >= _rule(rules, "limit")

## Dolan tarafın kötü sonu ("" yoksa). İkisi birden doluysa devlet önce gelir.
static func bad_ending(values: Dictionary, rules: Dictionary) -> String:
	for side: String in ["state", "order"]:
		if reached(values, side, rules):
			return ENDINGS[side]
	return ""

static func _add(values: Dictionary, side: String, amount: int, rules: Dictionary) -> Dictionary:
	var result := values.duplicate()
	result[side] = _clamp(int(result[side]) + amount, rules)
	return result

static func _clamp(value: int, rules: Dictionary) -> int:
	return clampi(value, 0, _rule(rules, "limit"))

static func _rule(rules: Dictionary, key: String) -> int:
	return int(rules.get(key, DEFAULTS[key]))
```

```gdscript
func _check_ending(final_night: bool) -> void:
	var result := Endings.resolve(state.human_reports, state.fallen_reports, state.wrong_reports, state.wrong_serves, final_night, content.ending_rules)
	if result.id != "":
		_end(result.id)

## Teslimat biter: sorulup dosya verilmediyse soran işkillenir; o tarafın şüphesi dolduysa kötü son
## bu teslimatın sonunda gelir; yoksa gün ilerler.
func _finish_delivery() -> void:
	var side := _supplier_side()
	if state.day >= 2 and not state.delivery_reported:
		state.suspicion = Suspicion.after_decline(state.suspicion, side, _suspicion_rules())
	_check_bad_ending(side)
	if state.phase == "ending":
		return
	if state.phase == "morning_supplier":
		state.phase = "day"
		_reset_visit()
	elif state.phase == "night_supplier":
		_check_ending(state.mode == "story" and state.day == content.days.size())
		if state.phase != "ending":
			_restock("fallen")
			state.phase = "dawn"
			state.stage = "transition"

## Şüphe dolduysa o tarafın kötü sonu (yalnızca o tarafın teslimatında çağrılır).
func _check_bad_ending(side: String) -> void:
	if Suspicion.reached(state.suspicion, side, _suspicion_rules()):
		_end(Suspicion.ENDINGS[side])

func _end(id: String) -> void:
	state.ending = content.endings[id].duplicate(true)
	state.ending["id"] = id
	state.ending["variant"] = Endings.variant(state.wrong_reports, state.wrong_serves)
	state.phase = "ending"
	state.stage = "ending"

func _supplier_side() -> String:
	return "state" if state.phase == "morning_supplier" else "order"

func _suspicion_rules() -> Dictionary:
	return content.ending_rules.get("suspicion", {})
```

```gdscript
## Tedarikçinin satırları bitti. O tarafın şüphesi tehdit seviyesindeyse ve daha önce sorgulanmadıysan
## önce sorgu gelir; sonra dosya teslimi.
func _start_delivery_decision() -> void:
	var side := _supplier_side()
	var rules := _suspicion_rules()
	if state.day >= 2 and side not in state.interrogated and Suspicion.level(int(state.suspicion[side]), rules) == "threat":
		state.interrogated.append(side)
		state.interrogation = side
		state.stage = "questioning"
		return
	state.stage = "decision"

func _answer_interrogation(index: int) -> void:
	if state.stage != "questioning":
		return
	var answers: Array = content.pools.interrogations[state.interrogation].answers
	if index < 0 or index >= answers.size():
		return
	state.suspicion = Suspicion.after_answer(state.suspicion, state.interrogation, int(answers[index].effect), _suspicion_rules())
	state.verdict = str(answers[index].reply)
	state.interrogation = ""
	state.stage = "verdict"

## Tedarikçinin satırlarına, o tarafın şüphe seviyesine göre bir tavır satırı eklenir (sakinse eklenmez).
func _with_suspicion_line(lines: Array, side: String) -> Array:
	var level := Suspicion.level(int(state.suspicion[side]), _suspicion_rules())
	if level == "calm" or state.day < 2:
		return lines
	var variants: Array = content.pools.get("suspicion_lines", {}).get(side, {}).get(level, [])
	if variants.is_empty():
		return lines
	var result := lines.duplicate()
	result.append(variants[state.day % variants.size()])
	return result

## Şafakta kepengin altından gelen not: şüphesi en yüksek tarafın seviyesine göre; ikisi de sakinse yok.
func _door_note() -> String:
	var rules := _suspicion_rules()
	var side := "state" if int(state.suspicion.state) >= int(state.suspicion.order) else "order"
	var level := Suspicion.level(int(state.suspicion[side]), rules)
	if level == "calm":
		return ""
	return str(content.pools.get("door_notes", {}).get(side, {}).get(level, ""))
```

````markdown
## Şüpheler (devlet ve örgüt)

Devletin (Defne) ve örgütün (Vey) senden şüphesi gizlidir; oyuncu sayıyı görmez. Sayılar `endings.json` → `rules.suspicion` içindedir:

```json
"suspicion": {"wary": 34, "threat": 67, "limit": 100, "give_other": 15, "give_streak": 10, "give_trust": -10, "wrong_report": 20, "decline": 8, "wrong_serve": 12, "wrong_recipe": 5}
```

- **`give_other` / `give_streak`:** Bir tarafa dosya verince öteki tarafın şüphesi bu kadar artar. Art arda aynı tarafa her teslimde `give_streak` kadar fazlası eklenir.
- **`give_trust` / `wrong_report`:** Dosyayı alan tarafın şüphesi doğru kişide düşer, yanlış kişide artar.
- **`decline`:** Tedarikçi sorup sen dosya vermezsen onun şüphesi bu kadar artar.
- **`wrong_serve`:** İnsana Fallen içeceği devletin, Fallen'a insan içeceği örgütün şüphesini artırır.
- **`wrong_recipe`:** Doğru rafın yanlış içeceği (istediğinden başka bir insan ya da Fallen içeceği) müşterinin tarafını biraz işkillendirir.
- **Seviyeler:** `wary` ve `threat` eşikleri. Şüphe `limit`'e ulaşınca o tarafın bir sonraki teslimatında kötü son gelir (`state_arrest`, `order_vanish`).

Metinler `encounter_pools.json` içindedir:

- **`suspicion_lines.<state|order>.<wary|threat>`:** Tedarikçinin satırlarının sonuna eklenen tavır cümleleri. Her gün sıradaki seçilir.
- **`interrogations.<state|order>`:** Şüphe ilk kez `threat` olunca o tarafın teslimatında açılan sorgu. Bir `line` (soru) ve 2–4 `answers` içerir; her cevapta `text`, `effect` (şüpheye etkisi, negatif olabilir) ve `reply` (tedarikçinin karşılığı) bulunur.
- **`door_notes.<state|order>.<wary|threat>`:** Şafak ekranında, şüphesi en yüksek tarafın notu.

````
